# assets/vector

Drop Illustrator exports here (SVG, or PNG as a fallback) using the names in `docs/ASSET_INTEGRATION.md`.
A file that exists replaces the matching placeholder drawing; nothing else needs to change.

In use: `mitochondrion_body.svg`, `chloroplast_body.svg`. Everything else is still drawn in code by
`scripts/placeholder_art.gd`.
Keep `.ai` source files somewhere else.
